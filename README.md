# EndlessStamina

EndlessStamina is a Minecraft plugin designed to provide players with infinite stamina, allowing them to sprint continuously without fatigue. This plugin is perfect for servers and players who want to enhance their gameplay experience with unlimited sprinting capabilities.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to enable the plugin.

## Use

1. Once the server is running with the plugin installed, players can start sprinting.
2. The plugin will automatically handle the stamina regeneration, ensuring players can sprint indefinitely.
